# Эмулятор командной оболочки (вариант 22)

Консольный (CLI) эмулятор командной строки UNIX-подобной ОС на Python 3.

## Функции

- Приглашение к вводу содержит имя VFS: `vfs$ `.
- Парсер учитывает кавычки и раскрывает переменные окружения ОС:
  `$HOME`, `${USERNAME}`. Неизвестная переменная заменяется пустой строкой.
- Команды:
  - `ls`, `cd` — заглушки, выводят своё имя и аргументы;
  - `exit [N]` — выход с кодом N.
- Ошибки: неизвестная команда, незакрытая кавычка, неверные аргументы `exit`.

## Запуск и тесты

Нужен Python 3.8+.

```
run.bat
tests\test_repl.bat
```

## Пример

```
vfs$ ls -l $HOME
ls ['-l', 'C:\\Users\\User']
vfs$ foo
foo: command not found
vfs$ exit
```
