# Эмулятор командной оболочки (вариант 22)

Консольный (CLI) эмулятор командной строки UNIX-подобной ОС на Python 3.

## Функции

- Приглашение к вводу содержит имя VFS: `vfs$ `
  (если задан `--vfs`, имя — последняя папка пути).
- Парсер учитывает кавычки и раскрывает переменные окружения ОС:
  `$HOME`, `${USERNAME}`. Неизвестная переменная заменяется пустой строкой.
- Команды:
  - `ls`, `cd` — заглушки, выводят своё имя и аргументы;
  - `exit [N]` — выход с кодом N.
- Ошибки: неизвестная команда, незакрытая кавычка, неверные аргументы `exit`.

## Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script FILE` | путь к стартовому скрипту |

При запуске печатается отладочный вывод всех параметров (`[debug] ...`).

## Стартовый скрипт

Команды эмулятора по одной в строке, комментарии начинаются с `#`.
Каждая команда печатается после приглашения, затем её вывод — как
диалог с пользователем. При ошибке выполнение останавливается
с сообщением `script error at файл:строка`, код завершения 1.
Примеры: `scripts/start.txt`, `scripts/error.txt`.

## Запуск и тесты

Нужен Python 3.8+.

```
run.bat [--vfs PATH] [--script FILE]
tests\test_repl.bat          этап 1: команды и ошибки
tests\test_all_params.bat    этап 2: все параметры
tests\test_with_script.bat   этап 2: стартовые скрипты
tests\test_with_vfs.bat      этап 2: разные пути VFS
```

## Пример

```
vfs$ ls -l $HOME
ls ['-l', 'C:\\Users\\User']
vfs$ foo
foo: command not found
vfs$ exit
```
